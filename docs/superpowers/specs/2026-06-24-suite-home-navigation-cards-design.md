# Suite Home Navigation Cards Design

## Goal
Replace the Suite home page action grid with four lively navigation boxes that describe the product areas in the user's language and route to the existing pages.

## Scope
This slice changes the Suite home page only. The sidebar and mobile top navigation stay as they are.

## Navigation Boxes
1. Strategy
   - Brand/profile
   - Marketing plan
   - Generated work plans
   - Logs for Suite changes and generation history
2. Generation and Creation
   - Create
   - Content library
   - Product bulk
   - Calendar and campaigns when available
3. מאגר מידע
   - Leads
   - Customers
   - Future CRM-like data areas
4. Settings and Connections
   - Connections
   - Billing
   - Storage status
   - Settings-related operational setup

## Visual Direction
Use designed boxes with restrained color accents, icons, small readiness signals, and compact child links. The page should feel alive and organized, not like a flat list of buttons.

## Constraints
- Keep all visible text localized for Arabic, Hebrew, and English.
- Do not remove existing destination pages.
- Do not add new backend endpoints.
- Do not redesign the global sidebar in this slice.
