## Inputs

- Product specs.
- Architecture docs.
- Design docs.
- Code diffs.

- Files this agent writes.

1. Read required inputs.
2. Identify gaps, risks, or decisions.
3. Produce/update owned artifact.
4. Hand off to next owner.
5. Record open questions and risks.
