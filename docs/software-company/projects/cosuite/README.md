# co-Suite Project Room

This folder is the operating room for the co-Suite build.

It is owned by Project Management and used by all department agents to keep work documented, reviewable, and restartable.

## Current Decision

Start with **Milestone 1: Production Stabilization**.

We are not starting the full platform at once. The first goal is to make the existing web/API product stable, observable, and ready for predictable feature work.

## Files

- `kickoff.md`: project kickoff, decision gates, owners, communication rules.
- `milestone-01-production-stabilization.md`: first milestone scope, tasks, gates, and handoffs.
- `task-board.md`: active task board for departments.
- `status-log.md`: chronological PM status updates.
- `handoff-log.md`: department handoffs and review requests.

## Operating Rule

No work is considered started unless it appears in `task-board.md` with:

- an owner.
- a status.
- acceptance criteria.
- required handoff or review.

No work is considered done unless the status log records:

- what changed.
- how it was verified.
- what remains open.
- who receives the next handoff.
