# مراجعة المالك - نظام العمل القابل للتكرار

التاريخ: 2026-06-07 23:03

## الخلاصة

تم تثبيت طريقة العمل كشركة سوفتوير قابلة لإعادة الاستخدام، وليس كعملية خاصة بمشروع OneShare فقط. أي مشروع جديد يجب أن يمر بنفس المنظومة: إدارة منتج، فحص براند، تصميم قبل الكود، هندسة، تنفيذ، QA، ومراجعة نهائية.

## ما تم توثيقه

- تم إضافة ملف مدراء الأقسام: `docs/software-company/department-managers.md`.
- تم إضافة Workflow جديد: `docs/software-company/workflows/brand-and-design-intake.md`.
- تم تحديث `docs/software-company/operating-model.md` حتى يدخل فحص البراند والتصميم قبل أي شغل UI.
- تم تحديث `docs/software-company/README.md` حتى يوضح أن هذا النظام قابل لإعادة الاستخدام لمشاريع أخرى.
- تم إضافة اسم مدير داخل كل Agent قسم.

## قاعدة مهمة للمشاريع القادمة

إذا بدأنا مشروع جديد وفيه واجهة أو موقع أو تطبيق، لازم Product Manager يسأل عن ملف البراند إذا مش موجود:

- لوجوهات.
- ألوان HEX/RGB.
- خطوط.
- Brand book.
- أيقونات أو شخصيات.
- أمثلة تصميم.
- لغات وأسواق مستهدفة.

إذا ما في براند، يتم توثيق هذا الشي بوضوح، والتصميم يقترح هوية مؤقتة أو Starter identity بدل ما نبلش كود على افتراضات مخفية.
