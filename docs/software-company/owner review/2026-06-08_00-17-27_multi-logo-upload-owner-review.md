# ملخص للمالك - Multi-Logo Upload

التاريخ: 2026-06-08 00:17  
المسؤول: Noa Barak / Rami Saleh

## ماذا أنجزنا

قوّينا رفع اللوجوهات بحيث يدعم أكثر من صورة، ويحافظ على منطق واضح للرئيسي والبدائل.

## التعديلات

- تأكدنا أن خطوة Brand في onboarding تقبل رفع عدة ملفات مرة واحدة.
- أصلحنا الباكند حتى لا يستبدل `logo_url` مع كل ملف في المجموعة.
- أول لوجو مرفوع يبقى اللوجو الرئيسي.
- باقي اللوجوهات تُحفظ داخل `brand_logos` كبدائل.
- كل لوجو يحصل على metadata أفضل:
  - format
  - width / height عندما يمكن
  - shape: square / horizontal / vertical / vector / unknown
  - background: transparent / unknown
- صفحة Brand/Profile بعد إنشاء السوت صارت تقبل رفع عدة لوجوهات مرة واحدة.
- رسالة الرفع توضّح عندما يتم رفع وتصنيف عدة لوجوهات.

## لماذا هذا مهم

العميل قد يملك أكثر من نسخة لوجو:

- مربع للسوشيال.
- أفقي للموقع.
- شفاف.
- نسخة على خلفية فاتحة أو داكنة.

النظام الآن لا يعامل كل هذه الملفات كأنها صورة واحدة، بل يخزنها كبدائل قابلة للاستخدام لاحقًا في توليد المحتوى.

## حدود هذه الجولة

- لا يوجد بعد UI لاختيار اللوجو الرئيسي يدويًا من بين البدائل.
- حاليًا أول لوجو في الرفع هو الرئيسي.
