تقرير مراجعة المالك - توحيد Brand/Profile مع onboarding

التاريخ: 2026-06-08 01:26
المسؤولون: Layla Haddad / Design Manager، Samer Nassar / Developers Manager

ماذا أنجزنا

  • صفحة Brand/Profile بعد إنشاء السوت أصبحت أقرب لمنطق onboarding.
  • رفع صور الشخصيات صار يدعم أكثر من صورة مرة واحدة.
  • أضفنا حذف شخصية من صفحة التعديل.
  • أضفنا حذف صورة واحدة من صور الشخصية.
  • أزرار اختيار اللوجو الرئيسي تستخدم الآن ترجمة التطبيق بدل النص الإنجليزي الثابت.

لماذا هذا مهم

البيانات التي يبنيها المستخدم أثناء فتح السوت لازم تكون قابلة للتعديل لاحقاً بنفس الجودة. بدون ذلك يصبح onboarding مكاناً قوياً، لكن صفحة التعديل لاحقاً تصبح أضعف وتكسر ثقة المستخدم.

التحقق

  • تم تشغيل npm run build بنجاح.
  • لا يوجد كسر TypeScript أو Next build بعد التعديل.

الخطوة المقترحة التالية

  • فحص صفحة Create & Generate من ناحية ربط الخيارات بالباكند.
  • ترتيب حالات المحتوى Recent Content حتى تكون واضحة أكثر حسب النوع والحالة.
