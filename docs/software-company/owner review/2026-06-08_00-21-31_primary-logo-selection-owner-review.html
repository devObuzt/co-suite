ملخص للمالك - Primary Logo Selection

التاريخ: 2026-06-08 00:21 · المسؤول: Noa Barak / Rami Saleh

ماذا أنجزنا

بعد دعم رفع عدة لوجوهات، أضفنا القدرة على اختيار اللوجو الرئيسي يدويًا.

التعديلات

  • في خطوة Brand أثناء onboarding، كل لوجو بديل صار عنده زر Set primary.
  • في Brand/Profile بعد إنشاء السوت، كل لوجو بديل صار عنده زر Set primary.
  • اللوجو الرئيسي يظهر كـ Primary.
  • في Brand/Profile لم نعد نكرر نفس اللوجو مرتين إذا كان موجودًا كرئيسي وداخل قائمة البدائل.

لماذا هذا مهم

أحيانًا أول ملف يرفعه المستخدم ليس بالضرورة هو اللوجو الأفضل للاستخدام العام. الآن يستطيع تعديل القرار بدون إعادة رفع الملفات.

التحقق

  • npm run build نجح.

الخطوة المقترحة التالية

الانتقال إلى QA/polish أوسع لشاشات onboarding على الموبايل، خصوصًا خطوات الجمهور والبراند.
