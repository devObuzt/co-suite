تقرير مراجعة المالك - تحسين خطوة الشخصيات والبرزنتורز

التاريخ: 2026-06-08 01:23
المسؤولون: Layla Haddad / Design Manager، Samer Nassar / Developers Manager

ماذا أنجزنا

  • جعلنا إدخال اسم الشخصية وزر الإضافة مناسبين للهاتف.
  • أصبح رفع صور الشخصية واضحاً ومريحاً في كرت الشخصية.
  • أضفنا إمكانية حذف شخصية كاملة قبل بناء الاستراتيجية.
  • أضفنا إمكانية حذف صورة واحدة من شخصية بدون حذف الشخصية كلها.
  • أبقينا عدد الصور غير محدود من ناحية الواجهة، حسب الفكرة الأصلية لاستخدام الشخصيات لاحقاً في توليد المحتوى.

لماذا هذا مهم

خطوة الشخصيات ليست مجرد بيانات إضافية. هي بداية مكتبة references لصناعة المحتوى لاحقاً: صاحب المصلحة، صانع المحتوى، البرزنتور، شخصية 3D أو كرتونية. المستخدم لازم يقدر يجرب ويرفع ويصحح بدون خوف من الغلط.

التحقق

  • تم تشغيل npm run build بنجاح.
  • لا يوجد كسر TypeScript أو Next build بعد التعديل.

الخطوة المقترحة التالية

  • فحص صفحة Brand/Profile بعد إنشاء السوت.
  • توحيد تجربة اللوجوهات، الخطوط، والشخصيات بين onboarding وصفحة التعديل.
